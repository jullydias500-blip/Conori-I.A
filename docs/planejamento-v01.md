# Planejamento — Conori I.A. versão 0.1

## Objetivo
Construir a primeira base funcional, modular e testável da Conori.

## Escopo inicial
- [x] Estrutura inicial do projeto.
- [x] Aplicação executável por terminal.
- [x] Memória local mínima em SQLite.
- [x] Contrato para provedores de IA.
- [ ] Interface gráfica multiplataforma.
- [ ] Integração real com um provedor de IA online.
- [ ] Integração com modelo local/offline.
- [ ] Reconhecimento e síntese de voz.
- [ ] Palavra de ativação e botão de fala.
- [ ] Testes ampliados e empacotamento.

## Critério de conclusão
A versão 0.1 será considerada concluída quando os módulos implementados estiverem testados, documentados e executarem de forma estável. Itens não implementados devem permanecer marcados como pendentes.
