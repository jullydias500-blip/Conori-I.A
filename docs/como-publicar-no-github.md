# Como adicionar esta estrutura ao repositório GitHub

Repositório de destino: `jullydias500-blip/Conori-I.A`

## Pelo celular (navegador)

1. Baixe e extraia o arquivo ZIP.
2. Abra o repositório no GitHub.
3. Use **Add file > Upload files**.
4. Envie os arquivos e pastas extraídos.
5. Revise a lista antes de confirmar.
6. Use a mensagem de commit: `feat: adiciona estrutura inicial da Conori IA v0.1`.
7. Confirme em **Commit changes**.

## Atenção ao arquivo de apresentação atual

O repositório mostrado nas capturas contém `LEIA-ME.md`. Esta estrutura inclui `README.md`, que é o nome reconhecido automaticamente pelo GitHub. Depois de conferir o conteúdo, mantenha o `README.md` novo como apresentação principal e, se não precisar mais do antigo, remova `LEIA-ME.md` em uma alteração separada.

## Assets

Coloque a imagem oficial da personagem em `assets/images/`. Coloque o áudio escolhido em `assets/audio/` somente quando tiver o arquivo original disponível. Não renomeie nem substitua o áudio por outro sem autorização.

## Antes de publicar

- Não envie `.env` com chaves reais.
- Não envie banco de memória ou dados pessoais.
- Confirme que o repositório continua privado enquanto os direitos dos arquivos e a licença não forem definidos.
