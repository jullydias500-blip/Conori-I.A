# Módulo de voz — planejado

Escolhas já definidas para a Conori:
- Ativação por botão e por palavra de ativação.
- Funcionamento híbrido, online e offline.
- A voz oficial foi escolhida pela idealizadora, mas o arquivo de áudio precisa ser adicionado a `assets/audio/`.

Ainda não implementado nesta base:
- captura de microfone;
- detecção da palavra de ativação;
- reconhecimento de fala (STT);
- síntese de fala (TTS);
- alternância automática entre serviços online e locais.

A implementação deverá pedir permissão para usar o microfone, indicar quando estiver ouvindo e oferecer controles claros para pausar/desativar.
